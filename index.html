How I work

Clear discovery, explicit decisions, and delivery measured by outcomes, with AI doing the busywork in between. Every step answers one question: what has to be true for this to be worth building?

  1. 01

    Discover

    Map the workflow end to end, find the real constraint, and use interviews and data to set a baseline before anything gets built.

    • User interviews
    • Workflow mapping
    • Jobs to be done
    • Baselines
  2. 02

    Decide

    Write a tight PRD with problem, non-goals, metrics, and risks. Make the scope, quality, and timeline tradeoffs explicit and align early.

    • PRDs
    • Prioritization
    • Roadmaps
    • MVP scoping
  3. 03

    Deliver

    Ship in increments, instrument the outcome, and turn what we learned into the next release instead of a deck.

    • Agile delivery
    • Analytics
    • Iteration
    • Stakeholder updates
